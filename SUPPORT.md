# Support

Use the right channel so issues get triaged quickly and sensitive information
does not end up in public threads.

## Usage and Setup Questions

For installation help, configuration questions, or deployment guidance:

- Read [README.md](README.md)
- Read [CONTRIBUTING.md](CONTRIBUTING.md) for local setup and tooling
- Email `hello@kodlyft.com` if you need maintainer assistance

## Bug Reports

Open a GitHub issue when you can reproduce a product defect and can share:

- DI version
- Frappe and ERPNext versions
- Install method
- Reproduction steps
- Sanitized logs, screenshots, or payload samples

Use the issue templates so reports are consistent and actionable.

## Security Reports

Do not report vulnerabilities through public issues.

Follow [SECURITY.md](SECURITY.md) and email `security@kodlyft.com`.

## Response Expectations

- Community support is best effort
- Maintainers may request sanitized logs or additional reproduction detail
- Security reports are handled separately from normal support questions
